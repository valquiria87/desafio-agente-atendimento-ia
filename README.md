Caso 1 — Agente de Atendimento com IA para Criadores de Conteúdo. 
Objetivo: desenvolver e testar um agente de atendimento com IA para auxiliar criadores do TikTok, Instagram e YouTube.
Ferramentas: Google Antigravity, engenharia de prompts e GitHub. 
Testes realizados: 1. Pergunta sobre serviços: o agente solicitou mais contexto sobre a necessidade do cliente. 
2. Pergunta sobre preços: o agente não informou um valor inventado e solicitou mais informações. 
3. Pergunta sobre o status do pedido: o agente solicitou dados para identificar o pedido. 
Resultados: os testes ajudaram a avaliar o comportamento do agente e identificar melhorias necessárias. 
Melhorias identificadas: definir uma lista oficial de serviços, integrar um sistema real para consultar pedidos e encaminhar situações incertas para atendimento humano.
